# mshaqfa.github.io

Personal academic website of **Mahmoud S. M. Shaqfa** — powered by [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).

Built on the [Academic Pages](https://academicpages.github.io/) theme (a fork of [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)).

## Run locally

```bash
bundle install
bundle exec jekyll serve --host 0.0.0.0 --port 4000
```

Or with Docker:

```bash
docker compose up
```

Open `http://localhost:4000`.
